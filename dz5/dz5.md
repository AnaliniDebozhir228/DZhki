# Домашняя работа. Типы данных и параметры

## Часть 1. Теоретический анализ

### Первичный ключ

Первичный ключ исходной таблицы:

`(student_id, subject_id, exam_date)`

`student_id` отдельно не подходит, потому что один студент может иметь несколько результатов. `subject_id` отдельно не подходит, потому что один предмет изучают и сдают разные студенты. `exam_date` тоже не подходит, потому что в одну дату может быть несколько результатов.

### Функциональные зависимости

- `student_id -> student_name, group_id`
- `group_id -> group_name`
- `teacher_id -> teacher_name`
- `subject_id -> subject_name`
- `(student_id, subject_id, exam_date) -> grade`

### Транзитивные зависимости

- `student_id -> group_id -> group_name`
- `teacher_id -> teacher_name`
- `subject_id -> subject_name`

### Нормальная форма

Исходная таблица находится в **1НФ**, потому что значения полей атомарные.

До **2НФ** таблица не доведена, так как есть зависимости неключевых атрибутов от части составного ключа. Например:

`student_id -> student_name`

Поэтому исходная таблица также не находится в 3НФ.
